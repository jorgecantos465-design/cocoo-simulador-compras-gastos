# Simulador de Compras y Gastos

Web app simple de Cocoo para evaluar si una persona puede sostener una compra o gasto importante antes de tomar la decisión.

## Alcance

- Sin login
- Sin base de datos
- Sin pagos
- Sin descargas
- Cálculos en frontend

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm test
npm run build
```

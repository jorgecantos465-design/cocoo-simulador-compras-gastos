# Skill: Frontend UI - simulador compras/gastos

## Objetivo
Mantener una UI clara para ingresar precio, costos, cuotas y ver impacto de caja.

## Cuando usarla
Usala para formularios, cards, grafico, responsive y estados visuales.

## Pasos obligatorios
- Revisar patrones en `src/components/Simulator.tsx`.
- Mantener lectura rapida de montos.
- Probar mobile y desktop.
- No ocultar alertas de caja insuficiente.

## Checklist antes de modificar
- El cambio no altera formulas.
- Estados contado/financiado/mixto contemplados.
- Textos largos entran en botones/cards.

## Checklist antes de finalizar
- Build exitoso.
- Flujo completo visible.
- Resultados y alertas no se superponen.

## Errores que debe evitar
- Priorizar decoracion sobre numeros.
- Dejar controles sin helper cuando cambian el calculo.
- Romper navegacion por pasos.

## Comandos de verificacion
- `npm run build`
- `npm run dev`

## Formato de reporte final
- Pantallas ajustadas.
- Estados verificados.
- Viewports.
- Riesgos visuales.

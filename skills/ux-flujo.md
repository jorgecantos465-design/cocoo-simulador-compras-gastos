# Skill: UX y flujo - simulador compras/gastos

## Objetivo
Hacer que el usuario entienda rapido si puede sostener una compra o gasto.

## Cuando usarla
Usala para pasos, labels, ayudas, lectura de resultados y escenarios de estres.

## Pasos obligatorios
- Ordenar datos desde situacion actual hacia decision.
- Explicar cuota, pago inicial y gasto nuevo.
- Mostrar alertas accionables.
- Mantener lenguaje no tecnico.

## Checklist antes de modificar
- Friccion actual identificada.
- El cambio no pide datos innecesarios.
- Resultados siguen explicando causa.

## Checklist antes de finalizar
- Flujo contado y financiado probado.
- El usuario ve caja final, caja minima y flujo mensual.
- Los escenarios son comprensibles.

## Errores que debe evitar
- Usar jerga de credito compleja.
- Mezclar indicadores de inversion.
- Ocultar "riesgo alto" detras de graficos.

## Comandos de verificacion
- `npm run dev`
- `npm run build`

## Formato de reporte final
- Flujo revisado.
- Copy/labels cambiados.
- Casos manuales.
- Riesgos de interpretacion.
